# 생물다양성 토론장

책으로 읽은 내용을 바탕으로 생물다양성 쟁점에 대해 **주장 2개와 근거 2개**를 작성하고, 가상 친구들의 생각과 비교해 보는 중학생용 웹 앱입니다. 설치 없이 브라우저에서 바로 실행됩니다.

## 주요 기능

- **도서 기반 토론 주제 3가지** — 각 주제마다 도서 요약(교보문고 책소개), 핵심 통계, 관련 기사·통계·누리집 링크를 제공합니다.
- **입장별 자료 탐색 안내** — 찬성/반대를 고르면 그 입장에서 어떤 자료를 찾으면 좋은지 안내합니다.
- **욕설·비속어 필터** — 강한 비속어는 등록 차단, 거친 표현은 순화 안내 후 확인. `시*발`, `ㅅ ㅂ` 같은 우회 표기도 탐지합니다.
- **개인정보 차단** — 이름·학교·학년/반·전화번호·이메일·주소·SNS 아이디·주민등록번호 등이 있으면 등록되지 않습니다.
- **무의미 입력 차단** — `ㅂㅂㅂ`처럼 자음·모음만 반복하거나 뜻 없는 글자는 등록되지 않습니다.
- **익명 별명** — 작성자와 가상 친구 모두 자동 생성된 별명을 사용합니다.
- **바탕화면 바로가기 추가** — 헤더의 버튼으로 앱처럼 설치할 수 있습니다(PWA). 설치가 지원되지 않는 브라우저에서는 기기별 추가 방법을 안내합니다.
- **오프라인 열기** — 한 번 방문하면 서비스 워커가 화면을 캐시해 인터넷이 느리거나 끊겨도 열립니다.

## 개인정보 처리

이 앱은 **개인정보를 수집하거나 저장하지 않습니다.** 작성한 내용은 브라우저 화면에만 표시되며 서버로 전송되지 않습니다. 백엔드도 데이터베이스도 없는 정적 HTML 파일 하나로 동작합니다.

## 토론 주제와 참고 도서

| 주제 | 도서 |
|---|---|
| 종 보존을 위해 동물원을 계속 유지해야 할까? | 친절한 교과 씨 생물 다양성으로 수다 떨다 (이고은, 데이스타) |
| 미호종개 서식지 인근의 지역 개발을 허가해야 할까? | 생물다양성 쫌 아는 10대 (김성호, 풀빛) |
| 금강의 미국가재·배스를 모두 포획해야 할까? | 여우와 토종 씨의 행방불명 (박경화, 양철북) |

도서 요약은 교보문고 책소개를 바탕으로 작성했습니다.

## 실행 방법

배포 주소: **https://samsunk25-hue.github.io/biodiversity-debate/**

`index.html`을 브라우저로 직접 열어도 동작합니다. 다만 바탕화면 바로가기 추가와 오프라인 기능은 `https://` 주소로 접속했을 때만 쓸 수 있습니다. 화면 디자인을 위해 Tailwind CSS·FontAwesome·SUIT 폰트를 CDN에서 불러오므로 첫 접속에는 인터넷 연결이 필요합니다.

| 파일 | 설명 |
|---|---|

| `manifest.webmanifest` | 앱 이름·아이콘·색상 등 설치 정보 |
