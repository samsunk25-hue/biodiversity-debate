# 생물다양성 토론장

책으로 읽은 내용을 바탕으로 생물다양성 쟁점에 대해 **주장 2개와 근거 2개**를 작성하고, 가상 친구들의 생각과 비교해 보는 중학생용 웹 앱입니다. 설치 없이 브라우저에서 바로 실행됩니다.

## 주요 기능

- **도서 기반 토론 주제 3가지** — 각 주제마다 도서 요약(교보문고 책소개), 핵심 통계, 관련 기사·통계·누리집 링크를 제공합니다.
- **정책 시뮬레이터** — 주제마다 슬라이더로 변수를 바꾸면 개체군 모형을 계산해 그래프·요약 숫자·판정으로 보여 줍니다. 결과 문장을 근거 칸에 바로 옮겨 적을 수 있습니다.
- **토론 타이머** — 글을 쓰기 시작하면 자동으로 작성 시간을 재고 10분마다 알려 줍니다. 준비·입론·교차조사·반박·최종 발언 카운트다운도 있습니다.
- **자기 점검 체크리스트** — 글을 쓰는 동안 주장·숫자·출처·과학 개념어가 들어갔는지 자동으로 확인해 줍니다.
- **예상 반론 카드** — 글을 다 쓰고 등록하면, 상대가 던질 만한 교차조사 질문과 답변 준비 힌트를 보여 줍니다.
- **입장별 자료 탐색 안내** — 찬성/반대를 고르면 그 입장에서 어떤 자료를 찾으면 좋은지 안내합니다.
- **욕설·비속어 필터** — 강한 비속어는 등록 차단, 거친 표현은 순화 안내 후 확인. `시*발`, `ㅅ ㅂ` 같은 우회 표기도 탐지합니다.
- **개인정보 차단** — 이름·학교·학년/반·전화번호·이메일·주소·SNS 아이디·주민등록번호 등이 있으면 등록되지 않습니다.
- **무의미 입력 차단** — `ㅂㅂㅂ`처럼 자음·모음만 반복하거나 뜻 없는 글자는 등록되지 않습니다.
- **익명 별명** — 작성자와 가상 친구 모두 자동 생성된 별명을 사용합니다.
- **바탕화면 바로가기 추가** — 헤더의 버튼으로 앱처럼 설치할 수 있습니다(PWA). 설치가 지원되지 않는 브라우저에서는 기기별 추가 방법을 안내합니다.
- **오프라인 열기** — 한 번 방문하면 서비스 워커가 화면을 캐시해 인터넷이 느리거나 끊겨도 열립니다.

## 개인정보 처리

이 앱은 **개인정보를 수집하거나 저장하지 않습니다.** 작성한 내용은 브라우저 화면에만 표시되며 서버로 전송되지 않습니다. 백엔드도 데이터베이스도 없는 정적 HTML 파일 하나로 동작합니다.

## 토론 주제와 참고 도서

| 주제 | 도서 |
|---|---|
| 종 보존을 위해 동물원을 계속 유지해야 할까? | 친절한 교과 씨 생물 다양성으로 수다 떨다 (이고은, 데이스타) |
| 미호종개 서식지 인근의 지역 개발을 허가해야 할까? | 생물다양성 쫌 아는 10대 (김성호, 풀빛) |
| 금강의 미국가재·배스를 모두 포획해야 할까? | 여우와 토종 씨의 행방불명 (박경화, 양철북) |

도서 요약은 교보문고 책소개를 바탕으로 작성했습니다.

## 정책 시뮬레이터

주제를 고른 뒤 **‘정책 시뮬레이터 — 변수를 바꿔 결과를 확인하기’** 를 펼치면 나옵니다. 슬라이더를 움직일 때마다 개체군 모형을 다시 계산해 꺾은선그래프, 요약 숫자 4개, 판정 문구, 계산에 쓰인 과학 개념을 함께 보여 줍니다.

| 주제 | 조작하는 변수 | 계산해서 보여 주는 것 | 다루는 과학 개념 |
|---|---|---|---|
| 동물원 | 사육 개체 수 · 서식지 복원 예산 비중 · 연간 방사 수 · 기간 · 계획 교배 여부 | 야생 개체군, 사육 개체 수, 유전다양성 유지율 | 유효 집단 크기(Ne), 유전자 부동·병목, 수용력(K) |
| 미호종개 | 개발 구간 비율 · 완충(이격) 거리 · 준설 강도 · 연간 방류 치어 · 기간 | 개체 수 변화, 서식지 질, 2019년(156개체) 대비 증감 | 서식지 질과 수용력, 알리 효과, 고유종 |
| 외래종 | 연간 포획(수매) 비율 · 산란장 제거율 · 수변 식생 복원 · 기간 | 토종·배스 개체 수, 어획 중 배스 비율, 누적 수매 비용 | 보상 반응, 포획률 vs 번식률, 회복 탄력성 |

**출발값은 실제 조사 자료를 씁니다.** 미호종개는 2019년 조사의 156개체, 외래종은 대청호 어획 중 배스·블루길 60~70%(모형에서는 71%)와 보은군 수매 단가 1kg당 3,200원, 동물원은 보전 유전학의 ‘100년 뒤 유전다양성 90% 유지’ 목표를 기준선으로 삼았습니다.

**성장률·생존율 같은 계수는 수업에서 변화를 눈으로 보기 위해 정한 값입니다.** 실제 생태계는 훨씬 복잡하므로 시뮬레이터 결과는 ‘경향’을 확인하는 용도로만 쓰고, 근거에는 실제 통계와 기사를 함께 인용하도록 화면에도 안내해 두었습니다. 그래프는 외부 라이브러리 없이 `<canvas>`에 직접 그리므로 오프라인에서도 동작합니다.

## 토론 수업에서 쓰는 기능

**토론 타이머** — 화면 오른쪽 아래 버튼으로 엽니다. 두 가지 모드가 있습니다.

- **글쓰기(자동 시작)** — 학생이 주장·근거 칸에 **첫 글자를 치는 순간 자동으로 시작**해 0부터 올라갑니다. **10분마다 화면이 깜빡이고 소리와 알림**으로 알려 줍니다(10분·20분·30분…). 타이머를 닫아 두었으면 오른쪽 아래 버튼이 대신 깜빡입니다.
- **토론 단계(카운트다운)** — 준비 30초 · 입론 3분 · 교차조사 2분 · 반박 2분 · 최종 발언 1분. ±30초로 조절할 수 있고, 남은 10초부터 매초, 끝나면 세 번 소리가 납니다.

소리는 음원 파일을 받아 오지 않고 웹 오디오로 그 자리에서 만들어 내며, 끌 수 있습니다. 시간은 시계 기준으로 계산해 다른 탭에 있어도 밀리지 않고, 타이머를 닫아도 버튼에 `글쓰기 10:10`처럼 시간이 보입니다.

**자기 점검 체크리스트** — 근거 칸 아래에 있습니다. 글을 쓰는 동안 네 가지를 자동으로 확인합니다.

| 확인 항목 | 판단 기준 |
|---|---|
| 주장이 입장이 드러나는 문장인가 | ‘~해야 한다’, ‘~하면 안 된다’ 같은 표현이 있는지 |
| 근거에 숫자가 있는가 | 개체 수·연도·비율 등 숫자 포함 여부 |
| 근거에 출처가 밝혀져 있는가 | 주제 데이터의 매체·기관 이름과 대조 |
| 근거에 과학 개념어가 있는가 | 주제별 개념어 목록과 대조 |

어느 칸이 비었는지 이름으로 알려 줍니다(예: “근거 ②에 숫자가 없어요”). 나머지 두 항목은 학생이 직접 체크하는 것이고, **다 채우지 않아도 등록은 막지 않습니다.** 등록을 막는 것은 욕설·개인정보·무의미 입력 검사뿐입니다.

**예상 반론 카드** — **글을 다 쓰고 등록하면** 결과 화면에 나타납니다. 먼저 스스로 생각을 정리한 뒤에 반론을 마주하도록 한 것입니다. 상대가 던질 만한 교차조사 질문 3개와 각각의 답변 준비 힌트를 접었다 펼칠 수 있고, 주제 3개 × 찬반 2가지 = 질문 18개가 미리 적혀 있습니다.

## 실행 방법

배포 주소: **https://samsunk25-hue.github.io/biodiversity-debate/**

`index.html`을 브라우저로 직접 열어도 동작합니다. 다만 바탕화면 바로가기 추가와 오프라인 기능은 `https://` 주소로 접속했을 때만 쓸 수 있습니다. 화면 디자인을 위해 Tailwind CSS·FontAwesome·SUIT 폰트를 CDN에서 불러오므로 첫 접속에는 인터넷 연결이 필요합니다.
